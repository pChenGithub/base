# 问题模式库（C / C++ 主动缺陷发现）

本库用于**规范之外**的主动问题发现。每条含：检出信号 / 典型后果 / 复核要点。

> **使用纪律**：命中 ≠ 确诊。必须回到代码上下文（数据流、调用方、生命周期、配置）确认后才定级；证据不足的写「疑似」并列出待确认点，**不臆断**。
> 与规范项重叠时（如"指针未判空"既属规范也属缺陷）取**更严级别**，只报一次。

## 1. 内存

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| M1 | 分配未释放 | `malloc`/`calloc`/`realloc`/`strdup` 无对应 `free`（尤其错误路径、提前 return 路径） | 内存泄漏（长时间运行累积） |
| M2 | 重复释放 | 同一指针两次 `free`；错误路径与正常路径都 `free` | double free 崩溃 / 堆破坏 |
| M3 | 悬空指针 | `free` 后未置 `NULL` 即继续使用 | 野指针崩溃 |
| M4 | 越界写 | 长度计算含 `±k`；`sizeof` 用错（指针 vs 数组）；拷贝长度取源长度而非目标容量 | 踩内存 / 堆破坏 / 静默数据错 |
| M5 | 未判空解引用 | 分配、查找、`strchr`/`strstr`/`fopen` 等返回值直接使用 | 段错误 |
| M6 | 释放非堆内存 | `free` 栈变量 / 字符串字面量 / 结构体成员 | 崩溃 |
| M7 | 结构体浅拷贝 | 含指针成员的结构体按值传递或赋值后双方各自 `free` | double free |
| M8 | 大小计算错 | `malloc(n)` 未乘 `sizeof(T)`；`sizeof(T*)` 当作元素总长 | 越界 / 分配不足 |
| M9 | `realloc` 用法错 | 直接用 `p = realloc(p, n)` 失败时原指针丢失 | 泄漏 + 悬空 |

## 2. 资源

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| R1 | 文件描述符未关闭 | `open`/`socket`/`accept`/`pipe` 无对应 `close`（含错误路径） | fd 耗尽 |
| R2 | 线程未回收 | `pthread_create` 后未 `join`/`detach` | 资源泄漏 / 僵尸线程 |
| R3 | 锁 / 信号量未释放 | 错误分支漏 `unlock`/`sem_post`；初始化未销毁 | 死锁 / 泄漏 |
| R4 | 系统调用返回值未检查 | `read`/`write`/`ioctl`/`open`/`stat` 返回值忽略 | 静默失败、脏数据 |
| R5 | 定时器 / 信号未注销 | `timer_create`/`signal`/`sigaction` 注册未清理 | 退出后回调野指针 |
| R6 | 文件 / 目录句柄未关闭 | `opendir` 无 `closedir`；`fopen` 无 `fclose` | fd 耗尽 |

## 3. 并发

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| C1 | 加锁后提前退出漏解锁 | `pthread_mutex_lock` 后存在 `return`/`goto`/`break` 未 `unlock` | 死锁 |
| C2 | 多锁顺序不一致 | 不同函数以相反顺序获取同一组锁 | 死锁 |
| C3 | 共享数据未加锁 | 全局/静态变量被多线程读写且无保护 | 竞态 / 数据错 |
| C4 | 信号量不配对 | `sem_wait` 与 `sem_post` 数量不匹配、超时未处理 | 阻塞 / 计数漂移 |
| C5 | 锁内阻塞操作 | 持锁期间做 IO / 长耗时 / 调用回调 | 长持锁、响应劣化、死锁 |
| C6 | 信号处理函数不安全 | handler 内调用 `printf`/`malloc`/非异步信号安全函数 | 崩溃 / 死锁 |
| C7 | 回调内再次加同一把锁 | 非递归锁重入 | 死锁 |

## 4. 边界与类型

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| B1 | 有符号 / 无符号比较 | `int i < sizeof(x)`、`len >= 0`（无符号恒真） | 条件失效 / 越界循环 |
| B2 | 整数截断 / 溢出 | 大范围类型赋给小类型；长度乘法溢出 | 越界 / 负数长度 |
| B3 | 下标 off-by-one | `<=` 遍历、`len - 1` / `len + 1` 偏差、循环变量被内部修改 | 越界读 / 漏处理 |
| B4 | 精度丢失 | `float`→`int`、`size_t`→`int`、`double` 比较用 `==` | 数据错 |
| B5 | 格式串与参数不匹配 | `%d` 传 `long`、`%s` 传非字符串指针、`%zu` 未用 | 崩溃 / 输出错 |
| B6 | 32/64 位差异 | `%ld`/`%lu`/`%zd` 用法、指针转 `int`（交叉编译 aarch64 / arm / x86 尤须注意） | 目标机行为错 |
| B7 | 移位越界 | 负数左移、移位数 ≥ 类型位宽、对负数做右移 | 未定义行为 |
| B8 | 字节序假设 | 网络/协议数据未 `htons`/`ntohs`、直接结构体强转 | 解析错 |
| B9 | 对齐 / 填充 | 结构体直接按字节布局收发（未 `#pragma pack` 或未逐字段序列化） | 协议不兼容 |
| B10 | 数组边界常量不一致 | 定义 `N` 处与使用处硬编码不同长度 | 越界 |

## 5. 错误处理

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| E1 | 返回值未检查 | 高危调用（`read`/`write`/`ioctl`/`snprintf`/`pthread_*`）返回值忽略 | 静默失败 |
| E2 | 静默失败 | 失败分支无日志、无返回、无标记 | 难排查 |
| E3 | 错误码语义错用 | 正负混用、0 表失败、成功返回 0 但调用方判断 `>0` | 逻辑反向 |
| E4 | 部分失败未回滚 | 多步初始化中途失败，已分配/已打开资源未释放 | 泄漏 / 状态不一致 |
| E5 | `errno` 被覆盖 | 中间调用覆盖 `errno` 后才读取 | 错误原因误导 |
| E6 | 错误分支 `return` 值不当 | 返回未初始化变量、返回截断码 | 误判 |

## 6. 逻辑

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| L1 | 条件恒真 / 恒假 | 自比较、类型范围外判断、`&&`/`||` 优先级错 | 分支失效 |
| L2 | 复制粘贴未改 | 相邻代码块变量名/字段名雷同但用途不同 | 隐性数据错 |
| L3 | 未初始化即使用 | C 局部变量未给初值（栈垃圾） | 随机行为 |
| L4 | `switch` 缺陷 | 缺 `break` 非本意穿透、缺 `default` | 走错分支 |
| L5 | 循环缺陷 | 条件永真无退出、循环变量越界修改、`continue` 跳过必要更新 | 死循环 |
| L6 | 比较误用 | `=` 代替 `==`、浮点 `==` | 逻辑错 |
| L7 | 除零 / 取模零 | 除数来自外部输入或未校验变量 | 崩溃 |
| L8 | 单位 / 量纲混用 | ms 与 s、字节与位、0.1°C 单位与整型混算 | 数值错 |

## 7. 嵌入式特有

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| X1 | `volatile` 缺失 | 中断 / DMA / 寄存器共享变量未加 `volatile` | 优化后读值不更新 |
| X2 | 上下文不允许的阻塞 | 中断 / 实时上下文调用阻塞函数、`malloc`、日志 | 卡死 / 丢中断 |
| X3 | 寄存器魔数 | 寄存器地址/位裸写未用宏封装、未注释 | 可维护性差 / 误改 |
| X4 | 延时精度误判 | `usleep`/`sleep` 精度假设、忙等未加让出 | 时序错 / CPU 占用 |
| X5 | 看门狗 | 未喂 / 误喂 / 超时未处理 | 意外复位 |
| X6 | 交叉编译差异 | 依赖宿主 `int` 宽度、依赖 `long` 长度、依赖结构体对齐 | 目标机异常 |
| X7 | 未对齐访问 | 对 `char*` 强转后按 `int*` 访问 | 架构相关崩溃（arm 尤甚） |

## 8. 接口与兼容

| 编号 | 模式 | 检出信号 | 典型后果 |
|---|---|---|---|
| I1 | **修改 / 删除既有对外接口** | 头文件中已有函数签名、结构体字段、宏、错误码被改动或删除 | **违反项目原则①（接口不修改、只能新增）**，破坏宿主工程编译 |
| I2 | 公共结构体字段增删改 | `ST_*` 等公共结构体字段顺序/类型变化 | ABI 不兼容 |
| I3 | 语义静默变更 | 参数含义、单位、返回值范围变化但未新增接口 | 调用方隐性错误 |
| I4 | 头文件新增依赖 | 公共头新增 include，改变宿主包含顺序 / 引入新依赖 | 宿主编译失败 |
| I5 | 全局符号冲突 | 新增非 `static` 全局函数/变量名与宿主或第三方重名 | 链接错误 / 覆盖 |
| I6 | 错误码取值冲突 | 新错误码与既有宏取值重复 | 误判 |

## 使用方式

1. 按 8 类逐条对照目标代码，命中记「疑似」+ 位置 + 推理链。
2. 回代码上下文确认（数据流、调用方、生命周期、编译目标），再定级。
3. 无法确认的写「疑似（待确认点：…）」，不用确定性措辞。
4. 同一问题在规范清单与本库都命中 → 取更严级别，合并只报一次。
