# rules-code-mgr 验收清单

## A. 创建新规则

- [ ] 创建前已盘点 `.codebuddy/rules/` 已有文件（查重 + 判定归属；已存在则并入不新建）
- [ ] 归属已按 SKILL.md **Step 0.1** 三条测试判定：**非编码规范不写入 `rules/`**（设计实现规范 → skills；项目事实 → `PROJECT.md`；用户特质 → `PROFILE.md`）
- [ ] 内容基底为通用最佳实践（按项目裁剪）；用户口述强调的规范已收录
- [ ] 文件名符合 `code_<语言|通用主题>.mdc`（固定前缀 `code`、无序号、小写下划线主体）
- [ ] 拆分符合决策规则：一个语言一个文件；仅跨语言通用主题独立成文件
- [ ] 文件主体（语言/主题）未与已有规则冲突
- [ ] frontmatter 含 `description`；有匹配限制时含 `globs`
- [ ] 必备单元齐全：适用范围 / 编程语言 / 语言版本特性（按需记录，不强制指定版本） / 注释风格 / 正向示例 / 反向示例
- [ ] 个性化扩展挂载点存在且格式固定
- [ ] 正向示例与反向示例均标注"正确/错误"并说明原因
- [ ] 示例与禁止项一一对应（示例支撑约束）
- [ ] **内容客观**：条文与示例未涉及具体项目 / 业务（无项目名、业务模块名、业务对象、设备型号、项目全局量、绝对路径），示例用通用或占位命名
- [ ] **示例自遵守**：正例自身完全合规（命名风格 / 段数 / 客观性 / 格式）；反例标注“错误”并给出合规改写，且只违反其说明的那一条
- [ ] 创建后已运行 `scripts/list_rules.sh`，命名 / frontmatter / 必备单元 / 客观性全部通过

## B. 修改现有规则

- [ ] 修改前已读取目标文件完整内容
- [ ] 仅定向替换目标单元，未破坏其他单元结构
- [ ] 修改后必备单元仍齐全，`code_` 前缀与文件主体未变
- [ ] 追加单条规范时已并入现有文件对应小节，未新建文件
- [ ] 追加/改写的条文已过 **Step 0.1** 归属判定；同一纪律未在别处（skill / `PROJECT.md`）重复维护，另一处只留「判据 + 指针」
- [ ] 正反示例与正文规范仍一致（未出现示例与规则矛盾）
- [ ] 示例自身合规：修改后的正例未违反命名 / 段数 / 客观性等条款；反例只违反其说明的那一条
- [ ] **每次修改后已校验**：运行 `scripts/list_rules.sh`，命名 / frontmatter / 必备单元 / 客观性 / 同文件重复条文全部通过（有不合规项已修正并重跑）
- [ ] 客观性：新增/改写的条文与示例未涉及具体项目或具体业务（项目名、业务模块、业务对象、型号、项目全局量、绝对路径）
- [ ] **描述精确**：`description` 与正文一致（覆盖适用对象 + 核心约束 + 关键差异），无正文外主题、无空话、未超长
- [ ] **无冗余**：同文件无重复条文、示例不重复正文；跨文件同一纪律只留「判据 + 指针」；无历史/背景/讨论类过程叙述
- [ ] **已精炼**：同义合并、长句拆为“判定 + 例外”、示例最小化、删除模糊限定词；精炼未改变判定口径与例外

## C. 编码（规范化）既有规则

- [ ] 已盘点 `.codebuddy/rules/` 全部文件，识别不合规命名
- [ ] 命名统一为 `code_<语言|通用主题>.mdc`；同语言拆散文件已合并（一个语言一个文件）
- [ ] 缺失的必备单元已补齐，已有内容未重复
- [ ] 每个文件尾部均有个性化挂载点
- [ ] 客观性：已识别并列出存量“涉及具体项目/业务”的内容（触碰该文件时收敛为通用描述）
- [ ] 变更项已列出（文件 → 变更）
- [ ] 编码完成后已运行 `scripts/list_rules.sh` 并通过

## D. 通用

- [ ] 未误改 `memory_load.mdc`（归官方机制/init-mem 范围）
- [ ] 未生成 .mdc 到 rules/ 以外目录
- [ ] 与既有规则无内容冲突（同主题不同规则间不矛盾）

## E. 语言覆盖度检查（主动提示）

- [ ] 已按源码扩展名/工程文件识别项目实际使用的编码语言（只计自研源码，排除第三方/依赖目录）
- [ ] 提示缺口时已给出依据（命中的扩展名与所在目录）
- [ ] 已逐一核对 `.codebuddy/rules/` 是否存在对应语言规范文件（对照 SKILL.md Step 7 期望文件名表）
- [ ] 存在缺口时已提示用户并给出建议（期望文件名 + 必备单元 + 可参考的 references），**未擅自新建**
- [ ] 同一语言未重复提示；用户拒绝后本会话不再提示
- [ ] 缺口提示未写入 memory logs、未触发蒸馏
